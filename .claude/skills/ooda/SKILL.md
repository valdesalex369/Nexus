# /ooda — Observe-Orient-Decide-Act Loop

## The Loop
1. **OBSERVE** — Gather data (MarketAgent, OnChainAgent, search_memory)
2. **ORIENT** — Analyze context (MiroFishAgent swarm, PredictionAgent, memory)
3. **DECIDE** — HubAgent picks strategy, assesses risk, requests approval if high-risk
4. **ACT** — Execute via ContentAgent/SEOAgent, store outcome in memory
5. **LEARN** — Record result, recalibrate evolution weights if 10+ outcomes
